## Things the handouts require that are easy to miss

- The proposal must be **one application whose parts interlock**. A menu over
  separate programs is explicitly rejected.
- Target scope is **A1 and A2 combined**, and it does **not** grow with team size.
- The backup idea must not depend on the same uncertain library as the main idea.
- **Every member needs an active role** in the first implementation step.
- A **required meeting with course staff** happens at each milestone, per the
  grading policy. The MS1 page does not mention it.
- MS2 and MS3 are graded from an uploaded ZIP, not from this repository, and
  both say to keep the repository access arrangement set up for MS1.
